## Entry

> WARNING: If you meet yourself, do not wave. He knows what you did, and he already told your mother.

## How it works

`main.py` writes the single one-line warning label (99 characters, within the 120-character gate) to `/output/entry.txt`. Deterministic, no network, Python 3.13 standard library only.
